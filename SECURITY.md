# Security Policy

## Scope

This repository is a demonstration integration. It is not approved for protected health information, clinical decisions, or emergency response.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Contact the repository owner privately through GitHub with a clear description, reproduction steps, impact, and a suggested mitigation.

Do not include real patient information in a report. Use synthetic examples only.

## Deployment expectations

Before any real deployment, add authentication, secret management, dependency scanning, rate limiting, encrypted transport, structured redaction, retention controls, threat modeling, and an appropriate legal/compliance review.
